# Gym Tracker

**Мобильное веб-приложение для учёта силовых тренировок.**  
Календарь тренировок, каталог упражнений, подходы с весом и повторениями, статистика прогресса — всё в одном экране, как у нативного приложения.

---

## Для кого

- Фитнес-студии и персональные тренеры, которым нужен простой дневник для клиентов  
- Стартапы и продукты в нише health & fitness  
- Предприниматели, которые хотят запустить свой трекер тренировок без разработки с нуля  
- Разработчики и агентства, которым нужен готовый MVP под ребрендинг и доработку  

---

## Что умеет приложение

### Дневник тренировок
Выберите день в календаре и ведите тренировку: какие упражнения делали и с какими результатами. История сохраняется по датам — удобно возвращаться к прошлым сессиям.

### Каталог упражнений
Готовый набор по группам мышц: руки, спина, плечи, грудь, ноги, пресс. Можно добавлять несколько упражнений сразу и отмечать особенности — гантели (двойной вес) или упражнения с собственным весом.

### Подходы: вес × повторения
Добавляйте, редактируйте и удаляйте подходы. Фиксируйте прогресс по каждому упражнению без таблиц и блокнотов.

### Статистика прогресса
Графики максимального веса и объёма. Для упражнений с собственным весом — суммарные повторения. Видно, растут ли результаты со временем.

### Личный кабинет
Регистрация и вход по email. В профиле — имя, почта и смена пароля.

### Работает как приложение на телефоне
PWA: можно установить на домашний экран, открывается на весь экран. Данные синхронизируются в облаке и доступны офлайн — тренировка не прервётся без интернета.

## Как выглядит продукт

1. **Вход / регистрация** — аккаунт за минуту  
2. **Главный экран** — календарь + список упражнений за выбранный день  
3. **Добавление упражнений** — выбор из каталога по группам мышц  
4. **Запись подходов** — вес и повторения  
5. **Статистика** — графики прогресса по упражнениям  
6. **Профиль** — данные аккаунта
